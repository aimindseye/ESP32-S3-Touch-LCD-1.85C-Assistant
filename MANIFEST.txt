Scope:
- Preserve accepted v0.1.2 hardware baseline
- Keep r3a/r4a/r5/r6/r7/r8/r9/r10 UI display as acceptable
- Do not accept r11 touch
- Keep universal horizontal swipe from anywhere
- Keep span-based swipe threshold at 20px
- Keep center tap threshold at 12px
- Use INT only to start a possible touch
- Once touch starts, poll CST816 every 8ms regardless of INT state
- Keep active polling for up to 180ms or until 3 consecutive no-touch reads
- Classify after active polling window/no-touch finish
- Gesture-first navigation with CST816 0x03 -> NextPage, 0x04 -> PreviousPage
- Use span direction when gesture is 0
- If gesture and span disagree, log both; prefer gesture only when span <35
- Avoid render while active touch polling is in progress
- Keep GPIO14/GPIO17/GPIO16 presence boot-only
- No SD refresh while UI validation is running
- Keep POWER GPIO6 experimental logging only
- Keep BOOT reserved while USB monitor is attached
